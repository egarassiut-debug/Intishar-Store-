# متجر رواق الإلكتروني المتكامل | Riwaq Multi-Category Store

تطبيق متجر إلكتروني حديث ومتكامل متعدد الأقسام والتصنيفات، يجمع بين تجربة تسوق سلسة تدعم الدفع المباشر والطلب عبر واتساب، مع لوحة إدارة ديناميكية لمتابعة المنتجات والمخزون والمبيعات.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد القرارات الرئيسية بناءً على إجاباتك:
> 1. **طبيعة المتجر**: متجر عام متعدد الأقسام (إلكترونيات، أزياء، عطور وتجميل، المنزل والديكور، ساعات وإكسسوارات).
> 2. **آلية إتمام الطلب**: دعم ثنائي متزامن — نموذج إتمام دفع متكامل (بطاقة / مدى / دفع عند الاستلام) + زر إتمام الطلب الفوري عبر واتساب بفاتورة منسقة تلقائياً.
> 3. **لوحة الإدارة**: توفير لوحة تحكم إدارية كاملة وسهلة الوصول لإدارة المنتجات، متابعة الطلبات، وتحديث المخزون.

---

### 1. Overview & Core Concept

- **طبيعة التطبيق**: منصة تجارة إلكترونية متطورة تدعم اللغة العربية واتجاه العرض (RTL) بشكل أصيل، موجهة للمتسوقين وتجار التجزئة.
- **الفئة المستهدفة**: المتسوقون الباحثون عن تجربة شراء سريعة وموثوقة، وأصحاب المتاجر الراغبون في إدارة مرنة لمنتجاتهم بدون تعقيدات.
- **القيمة الأساسية**: الجمع بين مرونة المتاجر العصرية وتسهيل التواصل الفوري عبر واتساب للزبائن في المنطقة العربية مع الحفاظ على دورة دفع وتتبع طلبات قياسية.

---

### 2. User Experience & Visual Design

#### Key User Flows
1. **استعراض وتصفح المنتجات**:
   - شريط علوي أنيق يحتوي على العلامة التجارية، شريط بحث حي وسريع، تصنيفات المنتجات، وزر السلة مع عداد ديناميكي، وزر التبديل إلى لوحة الإدارة.
   - قسم البنر الترويجي الرئيسي (Hero Campaign) يبرز أحدث العروض والتشكيلات.
   - شريط التصنيفات التفاعلي للتنقل الفوري بين الأقسام (الكل، إلكترونيات، أزياء، عطور، أدوات منزلية).
   - شبكة المنتجات (Product Grid) المنظمة مع تصفية حسب السعر والتقييم، وبحث فوري.
2. **نافذة تفاصيل المنتج (Product Modal)**:
   - صور عالية الوضوح مع معرض مصغر.
   - المواصفات والوصف، واختيار الخيارات (الألوان / المقاسات / السعة).
   - تقييمات العملاء وحالة التوفر في المخزون.
   - زر إضافة فوري إلى السلة مع إشعار مرئي سلس.
3. **سلة المشتريات (Slide-over Cart Drawer)**:
   - عرض قائمة المنتجات مع إمكانية تعديل الكميات أو الحذف.
   - تطبيق كوبونات الخصم الترويجية (مثل `RIWAQ10` أو `WELCOME`).
   - حساب فوري للشحن المجاني أو رسوم التوصيل والضريبة المضافة.
4. **صفحة إتمام الطلب (Checkout Flow)**:
   - **الخيار الأول (الدفع المباشر)**: إدخال بيانات التوصيل، اختيار طريقة الدفع (بطاقة مدى/ائتمانية، أو دفع عند الاستلام COD)، والحصول على رقم طلب فوري وشاشة تتبع حالة الشحنة.
   - **الخيار الثاني (الطلب عبر واتساب)**: إرسال ملخص الطلب والمنتجات والأسعار والعنوان برسالة منسقة إلى رقم واتساب المتجر بنقرة واحدة.
5. **لوحة تحكم الإدارة (Admin Dashboard)**:
   - بطاقات إحصائيات سريعة: إجمالي المبيعات، عدد الطلبات، تنبيهات نفاد المخزون، والمنتجات الأكثر طلباً.
   - جدول المنتجات: إضافة منتج جديد، تعديل الأسعار، الكميات، وإخفاء/تفعيل المنتجات.
   - جدول الطلبات: عرض الطلبات الواردة، تحديث حالتها (قيد المراجعة، جاري التجهيز، تم الشحن، مكتمل)، واستعراض بيانات العميل.

#### الهوية البصرية ونظام الألوان
- **التوجه الجمالي**: تصميم عربي معاصر راقٍ، نظيف وعالي الوضوح، يبتعد عن التعقيد والعناصر الزائدة ويلتزم بمبادئ التصميم الحديثة.
- **توزيع الألوان (60-30-10)**:
  - **60% الخلفية الأساسية**: خلفية حيادية مريحة للعين (درجات Slate الفاتحة والرمادي الدافئ النقي).
  - **30% الأسطح الهيكلية**: بطاقات منتجات بيضاء ناصعة مع حواف رفيعة هادئة وظلال ناعمة تفاعلية.
  - **10% لون التمييز واللمسات**: اللون الزمردي الملكي الفاخر (`Emerald #059669`) مع لمسات برونزية راقية تعكس الثقة والجودة.
- **الطباعة**: خطوط عربية واضحة ومقروءة متوافقة مع الأجهزة، مع أرقام جدولية مصفوفة (`tabular-nums`) لكافة الأسعار والكميات.

### 3. Key Product Decisions & Trade-Offs

- **إدارة الحالة ومزامنة البيانات**:
  - *الخيار المعتمد*: إدارة حالة متكاملة تعتمد على تخزين محلي تفاعلي مع تهيئة مسبقة لبيانات منتجات غنية واقعية باللغة العربية، مما يتيح تجربة فورية وسريعة بدون الحاجة لتهيئة قواعد بيانات خارجية في الخطوة الأولى مع إمكانية حفظ كل التعديلات والإضافات التي يجريها المستخدم في لوحة الإدارة.
  - *السبب*: سرعة فائقة في التفاعل وتوافق كامل مع بيئة العمل دون انقطاع، وإمكانية تعديل المنتجات وإضافة طلبات وتحديثها لحظياً.
- **دعم واتساب الذكي**:
  - *الخيار المعتمد*: توليد رابط `https://wa.me` منسق يتضمن أسماء العناصر، الكميات، الإجمالي، ورقم الطلب، وبيانات العميل.
  - *السبب*: تلبية متطلبات السوق العربي حيث يفضل العديد من الزبائن التواصل البشري وتأكيد الشحن فورياً.

#### الكيانات الأساسية للبيانات (Data Model)
- `Product`: المعرف، الاسم، الوصف، الفئة، السعر، السعر قبل الخصم، المخزون، التقييم، معرض الصور، الميزات، الخيارات (ألوان/مقاسات).
- `CartItem`: المنتج، الكمية، الخيار المختار.
- `Order`: رقم الطلب، المنتجات المشتراة، الإجمالي الفرعي، الخصم، الضريبة، الإجمالي النهائي، طريقة الدفع (أونلاين / واتساب / عند الاستلام)، بيانات المستلم (الاسم، الهاتف، العنوان، المدينة)، حالة الطلب (قيد المراجعة، جاري التجهيز، تم الشحن، تم التسليم)، تاريخ ووقت الإنشاء.
